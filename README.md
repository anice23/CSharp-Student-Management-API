# 🌐 ASP.NET Core Student Management RESTful API (3-Tier Architecture)

A production-ready backend RESTful API built using C# and ASP.NET Core, designed with a clean **3-Tier Architecture** to ensure separation of concerns and maintainability.

## 🚀 Key Features & Endpoints
* **Complete CRUD Operations:** Create, Read, Update, and Delete student records.
* **Database Integration:** Persistent data storage using SQL Server.
* **HTTP Status Codes & Routing:** Properly structured endpoints with standard REST conventions.

## 🏛️ Architecture (3-Tier Design)
1. **API / Presentation Layer:** Controllers, routing, and request/response handling.
2. **Business Logic Layer (BLL):** Core application rules, validation, and processing.
3. **Data Access Layer (DAL):** Database interactions, repositories, and data models.

## 🛠️ Tech Stack
* **Language:** C#
* **Framework:** ASP.NET Core / .NET
* **Database:** SQL Server / Entity Framework (or ADO.NET)
* **Architecture:** 3-Tier Design Pattern
